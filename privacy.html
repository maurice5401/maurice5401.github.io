Clipper

Privacy policy

Last updated: October 30, 2026

Clipper is a private tool. Maurice Hübscher runs it on his own computer and uses it only with YouTube channels he owns. This policy explains what Clipper does with Google user data.

Data Clipper accesses

When a channel owner signs in with Google and grants access, Clipper receives:

  • YouTube upload access (youtube.upload), to upload short videos to that channel.
  • Read access to YouTube data (youtube.readonly), to read the channel name and the view and like counts of videos Clipper uploaded.
  • OAuth tokens, which Google issues so Clipper can do the above.

Clipper does not access email, contacts, Google Drive, or any other Google data.

How the data is used

  • Upload clips that the channel owner created to the owner's own channel.
  • Show the channel name in the app, so it is clear which channel a clip goes to.
  • Show view counts of the uploaded clips, so the owner can see which clips work.

The data is not used for advertising, it is not sold, and it is not used to train AI models.

Storage

OAuth tokens and channel names are stored only locally, in a file on the owner's own computer. Clipper has no server and no database of its own. No Google user data is sent to third parties.

Sharing

Clipper does not share Google user data with anyone. Uploaded videos are, of course, public on YouTube, because the owner chooses to publish them there.

Deleting data and revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Removing a channel in Clipper deletes its stored tokens from the local file.

Google API Services User Data Policy

Clipper's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
